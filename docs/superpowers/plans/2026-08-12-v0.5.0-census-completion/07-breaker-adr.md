Content to carry:

- **Title (imperative digest):** "Trip the breaker, never burn the pool"
- **Scope / applies_to:** `src/pipeline/pipelined.rs`, `src/pipeline/mod.rs`, `src/batch.rs`, `src/commands.rs`, `src/cli.rs`
- **Decision:** `process` aborts the run when a run-global streak of
  consecutive claims resolves without a single success — default
  threshold **50** (operator-ratified 2026-08-12), operator flag
  `--breaker-threshold`, `0` disables. The trip cancels the existing
  ADR-0025 supervision token (workers finish their current row's state
  write and drain), the census records `breaker_tripped`, and the process
  exits with code **4**. The breaker never writes video state and never
  adds a second shutdown mechanism.
- **Why (evidence):** incident 2026-08-06 retried into a refusing endpoint
  for 60 unattended hours at ~8 failures/s — 1.81M attempts burned and an
  IP-reputation own-goal; incident 2026-08-10 cost ~1,400 attempts only
  because the operator watched. At the campaign's ~77% success rate the
  false-trip probability at 50 is ≈ 0.23⁵⁰ ≈ 10⁻³²; a pure dead-video run
  (~20% dead) cannot plausibly trip it (0.2⁵⁰). A WAF wave trips in
  seconds.
- **Guidance:**
  - The streak counts every claim outcome that is not a success —
    inline-terminal write-offs, retryable parks, cookie parks,
    transcribe-phase failures — and resets on any completed transcription
    (including `StaleAfterSuccess`: the transport worked; the breaker
    measures transport, not claim races).
  - Trip = `token.cancel()` on the ADR-0025 token, exactly once
    (swap-guarded); review rejects a second cancellation channel, worker
    aborts, or polling loops (ADR-0026 stands — workers still drain on
    `claim_next` → None).
  - DB-visible per the standing operator ruling: the verdict must be
    answerable from `batch_runs.census_json` alone; log lines are
    operationally invisible.
  - Exit code 4 joins the existing map (0 success, 1 verify-failed,
    3 zero-claims) via `CommandExit` — the library still never calls
    `process::exit`.
