# MADR archive (frozen)

Byte-exact history of the 35 MADR-format ADRs this repo accumulated before the
migration to the lean ADR format (July 2026). The **active decision model is
`docs/decisions/`** — lean records with routing frontmatter, managed by
`adg lean` and the write-adr plugin.

Records here are re-authored into `docs/decisions/` under their original IDs
and dates as the migration proceeds; records with no live enforcement surface
(process/operational history, the superseded 0034) stay archive-only. Nothing
in this directory routes into briefs, validates, or governs code. Do not edit —
it exists so `git log` and the original Context/Considered Options prose remain
reachable when a lean record's `## Why` needs its full backstory.
